## Featured project

### [solarnetwork-mcp](https://github.com/gopisrikrishna/solarnetwork-mcp)
An MCP server that lets AI agents read solar telemetry, find dated equipment faults, estimate lost energy and write technician work orders as PDFs. It follows one rule: say **"not assessed"** when the data cannot support an answer, instead of guessing "healthy".

- **10 tools**, from fleet discovery to PDF service reports
- **Peer-relative fault detection** across a fleet of public SolarNetwork nodes
- Built in **TypeScript** over the MCP stdio transport

[Read the write-up](https://gopisrikrishna.github.io/blog/solarnetwork-mcp/) · [Also on Medium](https://medium.com/@gopisrikrishna.y/solarnetwork-mcp-an-ai-agent-that-diagnoses-solar-faults-b92030844dce)
